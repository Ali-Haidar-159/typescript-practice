# TypeScript Practice Projects

This repository contains a collection of **TypeScript practice projects and exercises**. It covers a wide range of topics from **basic types** to **advanced concepts** like **generics, interfaces, classes, and utility types**.

## Topics Covered
- Basic Types: `number`, `string`, `boolean`, `array`, `tuple`, `enum`, `any`, `unknown`
- Functions: optional parameters, default values, rest parameters, function types
- Interfaces & Type Aliases: defining types, optional & readonly properties, function signatures
- Classes & OOP: constructors, access modifiers, inheritance, abstract classes
- Generics: generic functions, generic classes, generic interfaces
- Union & Intersection Types
